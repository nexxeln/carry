128+256=
Try an example

Addition/subtraction accepts 16 integer digits; multiplication accepts 8. Both accept two fractional places. Integer division accepts four digits and draws a remainder when needed. Browser notes.

Drawn pixels, unchanged text

The answer is visual, not added text. Copying 128+256= still gives you 128+256=. Screen readers read the underlying expression, not the drawn answer.

Same string, different font

Normal uses a regular monospace font. Carry applies its arithmetic substitutions. Debug uses Carry's debug font to expose internal glyphs. It is not a step-by-step engine trace. Unsupported expressions may stay as typed.
